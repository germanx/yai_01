## Длинный вход

Используем стратегию, аналогичную Sliding Window.
1. Сохраняем системный промпт
2. При обработке ошибок добавляется описание ошибки и промпт с инструкцией по корректировке ответа
3.1. Вариант 1
Отзывы обрезаем до размера, не превышающего 1500 токенов. Это довольно простая стратегия, в то же время 1500 токенов - достаточно большой размер текста для генерации валидной карточки. 
Данный подход не сработал. 
HF:

Альтернативный репозиторий "unsloth/llama-3.1-8b-Instruct" - тоже не сработал. Руками файлы загрузить также не удалось.

## Стоимость и решение

Ввиду блокировок пользователей из РФ со стороны западных вендоров, а также ввиду блокировок РКН, использование OpenRouter не представляется возможным. Использование средств обхода блокировок в рамках обучения для меня не приемлемо. 
Использование российских агрегаторов для доступа к иностранным API не выглядит надежным решением ввиду рисков контрагентов. 

В рамках проекта сравнивал варианты вызова локальной модели через 2 различных API: OpenAPI и Ollama.
Значения latency/стоимости получились примерно одинаковыми (что логично).

(6839 / 3600 * 65) / 300 * 1000 = 412 руб. за 1000

Итог: 
Для промышленного использования организациями в РФ требуется развертывание локальных моделей. 
Помимо проблем с блокировками, имеются отраслевые ограничения. Например Закон о банковской тайне сейчас ограничивает возможность обработки информации о клиентах в облачных сервисах, в т.ч. в сервисах ИИ.
